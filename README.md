Sales BI Platform

An end-to-end business intelligence project for processing sales data, tracking key metrics, and preparing reports for Power BI.

What it does

Combines sales data from CSV files or a SQL Server source

Cleans and deduplicates records by order ID

Calculates revenue, profit, and other key performance indicators

Creates alerts for low margins and low daily revenue

Exports Power BI-ready CSV tables

Provides a web dashboard and scheduled report generation

Technology

Python, SQLite, SQL Server, Power BI, DAX, HTML, CSS, and JavaScript.
